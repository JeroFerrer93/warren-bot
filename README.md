# Warren-Bot

Warren-Bot es un pequeño proyecto web que ofrece una interfaz tipo chat para responder preguntas básicas de finanzas personales. La página está construida utilizando HTML, CSS y JavaScript.

## Instalación y uso

No se requiere ninguna instalación. Simplemente abre el archivo `index.html` en tu navegador web preferido y comienza a interactuar con el bot.
